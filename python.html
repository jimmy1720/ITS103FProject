Python Tutorial


Part 1 Python Syntax


Similar to many other programming languages, there are some syntax in Python that must be followed.

For part 1, we will learn about indentations and how to declare a variable in Python.


1.1 Indentation


Python uses indentation to indicate a block of code.
If proper indentation is not added, it will result in a syntax error.


Examples


The following code prints "Hello World" if 2 is larger than 1, which is obviously true:


  • 1
  • if 2 > 1:
  • 2
  •   print("Hello World!")

The following would result in a syntax error because it doesn't contain proper indentation:


  • 1
  • if 2 > 1:
  • 2
  • print("Hello World!")


Try it!

  • 1
  • if 2 > 1:
  • 2
  •   print("Hello World!")



Result:


  • Hello World!

1.2 Variables


You can create a variable in Python by simply assigning a variable to it.
Unlike many other programming languages, no declaration of variable type is needed.


Examples


The following code creates two variables, which are assigned integer 5 and string "Hello World!" respectively.


  • 1
  • x = 5
  • 2
  • y = "Hello World!"

You can simply call the variable names when using them:


  • 3
  • x = x + 5 # Adds 5 to x ( The result is 10 )
  • 4
  • print(y) # Prints "Hello World!"
