Part 1 Python Syntax


Similar to many other programming languages, there are some syntax in Python that must be followed.

For part 1, we will learn about indentations and how to declare a variable in Python.


1.1 Indentation



Python uses indentation to indicate a block of code.
If proper indentation is not added, it will result in a syntax error.


Examples


The following code prints "Hello World" if 2 is larger than 1, which is obviously true:


  • 1
  • if 2 > 1:
  • 2
  •   print("Hello World!")

The following would result in a syntax error because it doesn't contain proper indentation:


  • 1
  • if 2 > 1:
  • 2
  • print("Hello World!")

1.2 Variables


You can create a variable in Python by simply assigning a variable to it.
Unlike many other programming languages, no declaration of variable type is needed.


Examples


The following code creates two variables, which are assigned integer 5 and string "Hello World!" respectively.


  • 1
  • x = 5
  • 2
  • y = "Hello World!"

You can simply call the variable names when using them:


  • 3
  • x = x + 5 # Adds 5 to x ( The result is 10 )
  • 4
  • print(y) # Prints "Hello World!"

  • 3

  • 5

1.3 Comments


Comments are used to explain the code, and are not executed by the Python interpreter.
Simply add a "#" sign before a line to make it a comment.


Examples


  • 1
  • # This is a comment
  • 2
  • x = "Hello World!" # This is also a comment

End of Part 1.



Part 2 Python Data Types


Variables can store data of different data types. Here are some basic data types that Python has by default:


Category Data Types
Numeric types: int, float, complex
Boolean type: bool
Text type: str
Sequence types: list, tuple, range
Mapping data type: dict
Set type: set

2.1 Numeric Data Types


Python supports three different numeric data types:


Type Description
int Integers, positive or negative, without decimals, of unlimited length
float Float, positive or negative, containing one or more decimals
complex Complex numbers, written with a "j" as the imaginary part

Examples


  • 1
  • x = 1 # int
  • 2
  • y = 2.8 # float
  • 3
  • z = 1j # complex

2.2 String Data Type


Strings are used to store text. Strings are surrounded by either single quotation marks, or double quotation marks.


Examples


  • 1
  • x = "Hello World!" # str

2.3 Boolean Data Type


Boolean represents one of two values: True or False.


Examples


  • 1
  • x = True # bool
  • 2
  • y = False # bool

2.4 Sequence Data Types


Python has three built-in sequence data types:


Type Description
list List is a collection which is ordered and changeable. Allows duplicate members.
tuple Tuple is a collection which is ordered and unchangeable. Allows duplicate members.
range Range is a collection which is ordered and unchangeable. Does not allow duplicate members.

Examples


  • 1
  • x = ["apple", "banana", "cherry"] # list
  • 2
  • y = ("apple", "banana", "cherry") # tuple
  • 3
  • z = range(6) # range

2.5 Mapping Data Type


Python has one built-in mapping data type, which is dictionary.
Dictionaries are used to store data values in {key:value} pairs.


Examples


  • 1
  • x = {"a" : 10, "b" : 20, "c" : 30} # dict

2.6 Set Data Type


Sets are used to store multiple items in a single variable.


Examples


  • 1
  • x = {"apple", "banana", "cherry"} # set

2.7 Mutable and Immutable Data Types



In Python, data types are divided into two categories: mutable and immutable.
Immutable data types are data types that cannot be changed after they are created.
While mutable data types are the opposite: They can be changed after they are created.


Mutable Data Types
list
dictionary
set

Immutable Data Types
int
float
complex
bool
string
tuple
range
frozenset
